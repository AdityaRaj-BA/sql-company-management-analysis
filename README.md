# 🗄️ SQL Company Management Analysis

> A comprehensive SQL database project demonstrating relational database design, advanced SQL queries, joins, aggregate functions, window functions, and business-oriented data analysis.

---

# 📖 Project Overview

This project is designed to demonstrate practical SQL skills by creating and managing a relational company database. It covers database creation, table relationships, data manipulation, analytical SQL queries, and advanced SQL concepts used in real-world business scenarios.

The project simulates a company management system involving managers, staff members, and customers while performing meaningful business analysis using SQL.

---

# 🎯 Project Objectives

- Design a relational database.
- Create multiple interconnected tables.
- Maintain data integrity using primary and foreign keys.
- Perform CRUD operations.
- Analyze business data using SQL.
- Demonstrate advanced SQL querying techniques.

---

# 🏢 Database Structure

The database consists of multiple related tables representing a company management system.

Example entities include:

- Manager
- Staff
- Customer

The tables are connected using appropriate relationships to maintain database integrity.
